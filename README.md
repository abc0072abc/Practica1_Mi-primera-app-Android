# 🎮 Biblioteca de Videojuegos

> [!IMPORTANT]
> **Toda la documentación detallada de este proyecto se encuentra en [`docs/Memoria.pdf`](docs/Memoria.pdf).**

## 📌 Descripción del proyecto

Biblioteca de Videojuegos es una aplicación Android diseñada para representar una biblioteca personal donde se pueden organizar videojuegos. El proyecto se centra en el diseño de la interfaz y en la personalización de los recursos visuales de la aplicación.

## 🖥️ Pantallas

La aplicación cuenta con dos pantallas diseñadas:

* **Pantalla principal:** muestra el título de la biblioteca, una ilustración y un botón para añadir videojuegos.
* **Pantalla para añadir videojuegos:** contiene un formulario con campos para introducir el nombre, la plataforma, el género, el estado y la valoración de un videojuego.

## 🎨 Recursos y diseño

En el proyecto se han trabajado los siguientes recursos:

* **Textos:** centralizados en `strings.xml` para facilitar su mantenimiento.
* **Internacionalización:** textos disponibles en español e inglés.
* **Imágenes:** recursos vectoriales y bitmap.
* **Colores:** paleta personalizada con tonos oscuros, morados y azules, además de colores específicos para los botones de guardar y cancelar.
* **Estilos y tema:** estilos reutilizables y un tema personalizado.
* **Icono:** icono propio para la aplicación.

## 🛠️ Tecnologías utilizadas

* Android Studio.
* Java.
* XML para el diseño de las interfaces.
* Recursos de Android para textos, imágenes, colores, estilos y temas.

## 🚀 Mejoras futuras

Como mejora futura, se plantea implementar filtros para buscar videojuegos según diferentes criterios, facilitando la localización de videojuegos concretos. También se podría ampliar la funcionalidad de la aplicación para gestionar la biblioteca de forma más completa.
